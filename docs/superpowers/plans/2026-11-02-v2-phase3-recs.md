# V2 Phase 3 — Recommendation depth: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Execute your own task only. Steps use checkbox
> (`- [ ]`) syntax. Write progress to your report file as you go.

**Goal:** For any in-progress set, ≥ 8 of the top-10 suggestions are key-compatible AND within ±6% tempo AND move
energy toward the arc target, drawn from the DJ's own crate + real-set neighbours + similar tracks, staying in the
set's style lane, each with its reasons.

**Architecture:** A client-side *crate* (everything the DJ has added or imported, persisted locally) becomes the
primary candidate pool, sent with each suggest request and enriched from the server metadata cache. A *style* signal
(Last.fm tags mapped onto a small DJ taxonomy, cached like other metadata) gives each track lanes; the engine scores
lane fit against the recent set and ranks spec-compliant candidates first. Similar tracks are gathered for the last
three tracks, not one. A *radio mode* chains top suggestions for fast evaluation, and a recommendation bench + blind
rating page measure criterion 3 and the owner's rating.

**Tech Stack:** TypeScript, Next.js 16 route handlers, React 19, Vitest. No new dependencies.

**Spec:** `docs/specs/2026-11-01-v2-product-plan.md` (Phase 3, "working website" criterion 3).
Rules: `docs/research/mixing-rulebook.md` (Camelot/BPM/energy rules — normative).

## Review Focus

1. Empty or tiny crate (first-time user, non-demo): suggestions still appear (neighbours/similar), with a hint to import a playlist — Task 1 test `tiny crate falls back`.
2. A crate of 2000 tracks must not make each suggest request slow or huge — Task 1 test `payload capped and request < 1 s with 2000-track crate (mocked providers)`.
3. Tracks with no tags (new promos) must not be punished as "off-lane" — neutral style score — Task 4 test `unknown style is neutral`.
4. A set that deliberately changes lane (melodic → techno) mid-set: suggestions follow the most recent tracks, not the opener — Task 4 test `lane follows recency`.
5. Radio mode must stop at the planned set length, on any error, and when the user interacts; never loops on a single repeated track — Task 5 tests.
